# OMS React Client

This is the React-based client/analytics interface for the Order Management System.

## 🚀 Getting Started

### Prerequisites
- Node.js
- NPM

### Running the App
From the root of the monorepo:

```bash
npx nx serve oms-react
```

Navigate to `http://localhost:4200/` (Note: Default port might conflict with Angular if running simultaneously, check console output).

### Testing
```bash
npx nx test oms-react
```

### Build
```bash
npx nx build oms-react
```
