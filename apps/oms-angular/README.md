# OMS Angular Dashboard

This is the Angular-based operational dashboard for the Order Management System.

## 🚀 Getting Started

### Prerequisites
- Node.js
- NPM

### Running the App
From the root of the monorepo:

```bash
npx nx serve oms-angular
```

Navigate to `http://localhost:4200/`.

### Testing
```bash
npx nx test oms-angular
```

### Build
```bash
npx nx build oms-angular
```
